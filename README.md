# onus-internal-page

One page that links to the ONUS internal warehouse tools, so staff only need one bookmark.

## Tools on the page

| Tool | Link |
|---|---|
| CycleCount Pro | https://xperia888.github.io/CycleCountPro/ (Monitoring Center: `monitor.html`) |
| Outbound Staging | https://xperia888.github.io/outbound-stage-manager/ (Chino, TV dashboard, Order Intake) |

## Adding a tool

Open `index.html`, copy one `<section class="tool">` block, and change the name, description and links.

## Publishing

Turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch `main`, folder `/`). The page will then be at https://xperia888.github.io/onus-internal-page/.
